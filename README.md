## ✨ What is NutriPro?

NutriPro transforms how people manage their nutrition. Instead of generic meal plans and tedious manual macro tracking, NutriPro uses **AI** to build precision-personalized meal plans, generate chef-grade recipes from any ingredients, scan your fridge with computer vision, and coach you 24/7 — all in a stunning dark-mode interface.

> **"The first AI planner that actually understands macro cycling."**

## 🚀 Feature Highlights

| Feature | Description |
|---|---|
| 🧠 **AI Meal Plans** | 7-day personalized plans generated by Groq LLaMA 3, tailored to your goals, macros, dietary restrictions, and cuisine preferences |
| 👨‍🍳 **Smart Recipes** | Generate chef-grade recipes from any prompt or from ingredients you already have |
| 🛒 **Grocery Lists** | Auto-generated, aisle-sorted shopping lists synced to your meal plan |
| 📸 **Fridge Scanner** | Snap your fridge → vision AI identifies ingredients → get instant recipe suggestions |
| 🤖 **NutriAI Coach** | 24/7 conversational AI nutrition coach with context awareness |
| 📊 **Macro Tracker** | Real-time dashboard with ring charts, weekly trends, and AI-generated insights |
| 🎯 **Smart Onboarding** | Multi-step profile quiz captures goals, body metrics, dietary needs, and preferences |
| 🔐 **JWT Auth** | Secure access + refresh token rotation with bcrypt password hashing |

## 🛠️ Getting Started

### Prerequisites
- **Node.js** ≥ 18.0.0
- **npm** ≥ 9.0.0
- API keys: Groq (required), Cloudinary (optional for fridge scanner), Google Cloud Vision (optional)

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/nutrition-planner.git
cd nutrition-planner
```

### 2. Set up the Server

```bash
cd server
cp .env.example .env
```

Edit `server/.env`:
```env
DATABASE_URL=file:./prisma/dev.db
JWT_SECRET=your-super-secret-jwt-key-here
JWT_REFRESH_SECRET=your-refresh-secret-here
GROQ_API_KEY=your-groq-api-key
PORT=3000
NODE_ENV=development
```

```bash
npm install
npm run db:generate      # Generate Prisma client
npm run db:migrate       # Run database migrations
npm run db:seed          # (Optional) Seed sample data
npm run dev              # Start server at http://localhost:3000
```

### 3. Set up the Client

```bash
cd client
cp .env .env.local       # Already has defaults
```

Edit `client/.env`:
```env
VITE_API_URL=http://localhost:3000/api/v1
VITE_GROQ_API_KEY=your-groq-api-key   # For client-side NutriAI chat
```

```bash
npm install
npm run dev              # Start client at http://localhost:5173
```

### 4. Open the app

Navigate to **http://localhost:5173** → Create an account → Complete onboarding → Start generating!

## 🔌 API Reference

### Authentication
```
POST   /api/v1/auth/register    → Register new user
POST   /api/v1/auth/login       → Login, returns access + refresh tokens
POST   /api/v1/auth/refresh     → Rotate refresh token
POST   /api/v1/auth/logout      → Invalidate refresh token
```

### Users
```
GET    /api/v1/users/profile    → Get authenticated user + profile
PUT    /api/v1/users/profile    → Update profile (metrics, goals, preferences)
```

### Meal Plans
```
POST   /api/v1/meal-plans/generate   → AI-generate 7-day meal plan
GET    /api/v1/meal-plans            → List user's meal plans
GET    /api/v1/meal-plans/:id        → Get specific plan with all meals
DELETE /api/v1/meal-plans/:id        → Delete meal plan
```

### Recipes
```
POST   /api/v1/recipes/generate   → AI-generate recipe from prompt
GET    /api/v1/recipes            → List saved recipes
```

### Grocery
```
POST   /api/v1/grocery/generate          → Generate list from meal plan
GET    /api/v1/grocery                   → List all grocery lists
PUT    /api/v1/grocery/:id/items/:itemId → Toggle item checked state
```

### AI & Vision
```
POST   /api/v1/image/analyze   → Upload fridge image → get ingredient list + recipes
POST   /api/v1/ai/chat         → Server-side NutriAI conversation
```
